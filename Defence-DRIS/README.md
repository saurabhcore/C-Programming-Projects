# DRIS - Defence Resource Intelligence System

## 📌 Project Overview

DRIS (Defence Resource Intelligence System) is a simple C-based
resource management and risk analysis project.

The program takes basic resource information such as personnel,
vehicles, fuel, food and medical resources and calculates an
overall risk score.

It then classifies the situation as:

- LOW RISK
- MODERATE RISK
- HIGH RISK

The system also gives a priority recommendation based on the
resource that needs the most attention.

> This is an educational and fictional resource-management
> simulator. It is not designed for real-world military operations.

---

## 🎯 Objectives

The main objectives of this project are:

- Store different resources using C structures.
- Take resource information from the user.
- Check resource levels.
- Calculate a risk score.
- Classify the overall risk.
- Identify the priority resource.
- Practice basic C programming concepts.
