# Student Management System

A simple Student Management System built using C programming.

## Features

- Add Student
- Display All Students
- Search Student by Roll Number
- Exit Program

## Student Information

The program stores:

- Roll Number
- Name
- Age
- Marks

## Concepts Used

- Structures
- Arrays
- Functions
- Strings
- Loops
- If-Else
- Switch Case
- Input and Output
