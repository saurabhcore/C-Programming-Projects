# 📚 Library Management System

A simple Library Management System built using C programming.

## 🚀 Features

- Add Book
- Display All Books
- Search Book
- Add Member
- Display Members
- Issue Book
- Return Book
- Exit

## 📌 Book Information

Each book contains:

- Book ID
- Book Title
- Author Name
- Availability Status

## 👤 Member Information

Each member contains:

- Member ID
- Member Name

## 🧠 Concepts Used

This project uses:

- C Programming
- Structures
- Arrays
- Functions
- Strings
- Loops
- If-Else
- Switch Case
- Searching
- User Input / Output
