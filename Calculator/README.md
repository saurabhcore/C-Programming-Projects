# C Calculator

A simple calculator program built using C programming.

## Features 

- Addition
- Subtraction
- Multiplication
- Division
- Division by zero handling
- Invalid operator handling

## Concepts Used

- Variables
- Data Types
- Input and Output
- Switch Case
- If-Else
- Arithmetic Operators

## Example

Enter first number: 10
Enter operator (+, -, *, /): *
Enter second number: 5

Result = 50.00

## How to Run

Compile the program using a C compiler:

gcc calculator.c -o calculator

Then run:

./calculator
