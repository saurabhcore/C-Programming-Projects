# C Programming Projects

A collection of C programming projects focused on programming
logic, problem-solving, and practical application development.

## Projects

### 1. Calculator
A simple calculator program written in C for performing basic
arithmetic operations.


### 2. Student Management System
A C-based project for storing and managing student information.


### 3. Library Management System
A simple C project for managing library records and basic
book-related operations.


### 4. DRIS - Defence Resource Intelligence System
A fictional resource management and risk analysis system built
in C.

DRIS takes resource information such as personnel, vehicles,
fuel, food, and medical resources and calculates an overall
risk level and priority recommendation.

> DRIS is an educational and fictional resource-management
> simulator and is not intended for real-world military
> operations.
